## 🚀 Quick Start & Usage

### 1. Run the Component API Server & Live Dashboard
```bash
npm start
```
- Open [http://localhost:3000](http://localhost:3000) in your browser.
- View live rendering of all 6 components side-by-side with endpoints and markdown embed tags.

### 2. Generate / Refresh Static SVGs Locally
```bash
npm run generate
```
This queries the GitHub API for `@rraviss0108`, generates all 6 SVG files, and writes them into `assets/components/`.

### 3. Automated Updates via GitHub Actions
The workflow [.github/workflows/update-readme.yml](file:///w:/Projects/rraviss0108/.github/workflows/update-readme.yml) automatically:
- Runs every 24 hours at midnight UTC (or on manual click via `workflow_dispatch`).
- Runs `npm run generate` using the GitHub Actions runner.
- Commits and pushes any updated SVG metrics directly back to your repo.
